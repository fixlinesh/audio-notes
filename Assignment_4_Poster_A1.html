5 Proposed Solution & 5-Stage Customer Journey

Originality: Connects a Web Audio Smart Acoustic Sensor (measuring classroom dB, SNR, and WPM to auto-trigger Biquad noise suppression) with EN/KZ/RU Summary, Glossary, Quiz & AI Teacher.

1. Aware
Misses fast lecture terms; scans QR.
2. Access
Opens PWA instantly (0 login wall).
3. Setup
Sensor enables Biquad filter >60dB.
4. Usage
Gets KZ/RU notes, 8 quizzes & cards.
5. Support
Edits notes, exports PDF & cloud sync.

6 Architecture & Tech Stack

1. Web Audio SensorLive dB/SNR + Biquad Filter (Browser)
2. React 19 + Vite PWATypeScript + Tailwind v4 Mobile/Web
3. Vercel Edge + GeminiGemini 2.5 Flash JSON Notes & Tutor
4. Supabase PostgreSQL3NF Schema + Kernel RLS + Storage

Why chosen: Zero-install PWA; PostgreSQL 15 guarantees ON DELETE CASCADE & Row-Level Security (auth.uid() = user_id); Gemini 2.5 Flash processes EN/KZ/RU in <1.5s.
